# SAE Web - Site Vitrine Mariage

## Description

Site web vitrine réalisé pour un événement de mariage, avec version française et anglaise. Le site comprend plusieurs pages : accueil, galerie photo, hébergement, menu, planning et support.

## Structure

```
SAE Web/
├── SiteWeb/
│   ├── Accueil.html / AccueilEn.html
│   ├── Galerie.html / Galery.html
│   ├── hotel.html / hotelEn.html
│   ├── Menu.html / MenuEn.html
│   ├── Planning.html / PlanningEn.html
│   ├── Support.html / SupportEn.html
│   ├── Wedding.html
│   ├── css/              # Feuilles de style (typographie, boutons, taille)
│   ├── img/              # Images du site
│   ├── Maquettes/        # Maquettes de conception
│   └── Persona.pdf       # Personas utilisateurs
├── bootstrap-5.1.3-dist/ # Framework CSS Bootstrap
└── capsuleVideo.zip      # Capsule vidéo de présentation
```
