# SAE 1.04 - Base de Données

## Description

Projet de SAE portant sur l'analyse de données et les requêtes SQL, appliqué au dataset du Titanic.

## Contenu

- **SAE_BDD-checkpointFin.ipynb** - Notebook Jupyter contenant l'analyse de données en Python
- **SAE_SQL.sql** - Fichier de requêtes SQL
- **titanic_train.csv** - Jeu de données du Titanic utilisé pour l'analyse
- **SAE-104-BD-21-22.pdf** - Sujet de la SAE

## Technologies

- Python (Jupyter Notebook)
- SQL
