# CakeCrush

## Description

Jeu de type match-3 (inspiré de Candy Crush) développé avec Pygame. Le joueur doit atteindre un score de 18 000 points en alignant des gâteaux sur une grille de 10x8.

## Lancement

```bash
pip install pygame
python main.py
```

## Structure

- **main.py** - Boucle principale du jeu, gestion des événements et affichage
- **cake.py** - Classe `Cake` (sprite Pygame) représentant un gâteau sur la grille
- **tab_cakes.py** - Classe `TabCakes` gérant la grille de jeu et la logique de match
- **analyseur.py** - Analyse des alignements sur la grille
