# SAE Maths - Fractales de Mandelbrot et Julia

## Description

Projet d'exploration algorithmique (SAE 202) portant sur les ensembles fractals de Mandelbrot et Julia. Le notebook contient :

- Les définitions mathématiques (nombres complexes, fractales)
- Le calcul du temps d'échappement pour chaque point du plan complexe
- La visualisation de l'ensemble de Mandelbrot
- Une animation de zoom vers un point remarquable (90 frames, ~8h de calcul en haute résolution)

## Contenu

- **SAE_Math.ipynb** - Notebook Jupyter avec le code et les explications
- **SAE_Math.html** - Export HTML du notebook
